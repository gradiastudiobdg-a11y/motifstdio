# Flow production pack — Kamu Boleh Istirahat

Draf template offline. Brainstorming dan penajaman naskah dapat dilakukan bersama Codex; tidak ada panggilan AI tersembunyi.

Alur: setujui frame referensi → buat gambar tiap adegan → animasikan gambar di Flow → impor hasil → susun dan trim di editor. Ketersediaan durasi mengikuti model dan rute yang kamu pilih di Flow; jika berbeda, ubah clipDuration dan susun ulang rencana. Untuk 4/6 detik pilih rute frame awal/akhir yang mendukungnya; rute Ingredients/References tertentu hanya mendukung 8 detik. Periksa pilihan aktif di Flow.

Prompt animasi hanya berisi arahan visual. Naskah suara berada di bagian terpisah untuk direkam atau dibuat di alat suara pilihanmu. Headline dan subtitle ditambahkan saat editing.
